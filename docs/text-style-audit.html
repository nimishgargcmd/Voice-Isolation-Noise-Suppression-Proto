why −0.41 vs −0.43  Both come straight from Apple's iOS 17pt tracking table. The bubbles use the SwiftUI/Figma body value (−0.41px); the list name uses the slightly tighter UIKit body value (−0.43px). At 17px the difference is ~0.02px/char — visually imperceptible. If you want exact parity, standardize the list name to −0.41px.
